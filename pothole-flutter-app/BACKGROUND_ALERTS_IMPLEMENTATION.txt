===============================================================================
HOW IT WORKS
===============================================================================

FOREGROUND (App Open):
1. User enables "Background Pothole Alerts" in Settings
2. App requests "Allow all the time" location permission
3. Starts WorkManager periodic task (15-minute interval)
4. Saves auth token to SharedPreferences for background access

BACKGROUND (App Closed):
1. WorkManager wakes up every 15 minutes
2. Checks if background tracking is enabled
3. Gets current device location (or last known location)
4. Calls backend API: GET /potholes/nearby?lat=X&lng=Y&radius=1000
5. Filters for severe potholes (risk = HIGH or SEVERE)
6. If found and not alerted in last 15min:
   - Shows notification with distance and count
   - Vibrates device (urgent pattern for severe)
   - Saves alerted pothole IDs to prevent duplicates

NOTIFICATION TYPES:
- Severe: "⚠️ SEVERE Pothole Alert: 2 severe potholes 350m away"
- Regular: "🚧 Pothole Alert: 3 MEDIUM potholes 500m away"

NEXT STEPS FOR USER
===============================================================================

1. INSTALL DEPENDENCIES
   cd pothole-flutter-app
   flutter pub get

2. SETUP FIREBASE (OPTIONAL BUT RECOMMENDED)
   - See FIREBASE_SETUP_GUIDE.md for detailed instructions
   - Download google-services.json from Firebase Console
   - Place in: pothole-flutter-app/android/app/google-services.json
   - Without Firebase: Local notifications still work, no push messaging

3. UPDATE ANDROID BUILD FILES (IF NOT ALREADY DONE)
   
   android/build.gradle - Add inside dependencies:
   ```
   classpath 'com.google.gms:google-services:4.4.0'
   ```
   
   android/app/build.gradle - Add at bottom:
   ```
   apply plugin: 'com.google.gms.google-services'
   ```

4. BUILD AND TEST
   flutter build apk
   flutter install
   
5. TEST BACKGROUND ALERTS
   - Open app and login
   - Go to Settings
   - Enable "Background Pothole Alerts"
   - Grant "Allow all the time" location permission
   - Click "Test Alert Now" to test immediately
   - Close app completely
   - Wait 15 minutes (WorkManager interval)
   - If near a severe pothole (within 1km), notification will appear

6. DISABLE BATTERY OPTIMIZATION (IMPORTANT!)
   - Device Settings > Apps > RoadGuard AI
   - Battery > Battery optimization > Don't optimize
   - This prevents Android from killing background tasks

BACKEND API ENDPOINT USED
===============================================================================

GET /potholes/nearby?lat={latitude}&lng={longitude}&radius=1000

Returns: List of potholes within radius, sorted by severity then distance
Filter: major_only=false (checks all potholes, not just severe)

The backend endpoint was already implemented in previous tasks.

===============================================================================
TROUBLESHOOTING
===============================================================================

ISSUE: "Firebase not configured" warning
FIX: This is OK! Local notifications still work. FCM is optional.

ISSUE: No background notifications received
FIX: 
  - Check "Allow all the time" permission granted
  - Disable battery optimization for app
  - Wait full 15 minutes for first check
  - Ensure you're within 1km of a severe pothole

ISSUE: "Background location permission denied"
FIX: Device Settings > Apps > RoadGuard AI > Permissions > Location > 
     Select "Allow all the time"

ISSUE: Background task not running
FIX:
  - Check battery optimization is disabled
  - Some phone manufacturers (Xiaomi, Huawei) need additional settings:
    - Enable "Autostart"
    - Disable "Battery saver"
    - Add to "Protected apps" list

ISSUE: Notification shows but no vibration
FIX: Check device is not in silent mode and vibration is enabled
